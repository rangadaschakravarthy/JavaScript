# Day 10 — Function Fundamentals

## 📌 Module Overview
Day 10 introduces JavaScript functions from absolute first principles. You will learn why functions are essential for DRY (Don't Repeat Yourself) code, function anatomy, declaration syntax, parameters vs arguments, return statements vs `console.log`, early returns, and single responsibility principles.

---

## 🎯 Learning Objectives
- Understand why functions exist (code reusability, abstraction, maintainability).
- Identify every component of a function declaration.
- Differentiate clearly between **parameters** (variables in declaration) and **arguments** (values passed during invocation).
- Understand parameter ordering, missing arguments (`undefined`), and extra arguments.
- Master the `return` statement and explain why `return` is fundamentally different from `console.log`.
- Apply early returns and guard clauses.
- Write functions adhering to Single Responsibility Principles (SRP).
