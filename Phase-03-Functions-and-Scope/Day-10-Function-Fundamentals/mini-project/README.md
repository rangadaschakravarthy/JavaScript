# Day 10 Mini-Project — Utility Function Library

## 1. Overview
The **Utility Function Library** is an interactive web dashboard and CLI suite demonstrating pure, single-responsibility functions for numbers, strings, and validation rules.

## 2. Functions Included
- `isEven(n)` / `isOdd(n)`
- `isPositive(n)` / `isNegative(n)`
- `findMax(a, b)` / `findMin(a, b)`
- `calculateAverage(a, b, c)`
- `calculateGrade(score)`
- `isEligibleToVote(age)`

## 3. How to Run
- **Browser**: Open `index.html` directly.
- **Node.js**: Run `node script.js`.
