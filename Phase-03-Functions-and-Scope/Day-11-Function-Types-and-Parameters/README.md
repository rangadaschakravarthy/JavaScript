# Day 11 — Function Types and Parameters

## 📌 Module Overview
Day 11 explores the full spectrum of function creation styles and parameter mechanisms in modern JavaScript. You will learn function expressions, anonymous vs named expressions, ES6 arrow functions, default parameters, rest parameters, the legacy `arguments` object, and IIFE design patterns.

---

## 🎯 Learning Objectives
- Compare function declarations vs function expressions.
- Master arrow function syntax, implicit returns, single-parameter shorthand, and returning object literals.
- Identify the arrow function object returning syntax gotcha `() => ({ key: val })`.
- Apply default parameters (`param = defaultValue`) and understand when defaults trigger (`undefined` vs `null`).
- Collect variadic arguments using ES6 rest parameters (`...rest`).
- Understand the array-like `arguments` object in standard functions vs arrow functions.
- Write Immediately Invoked Function Expressions (IIFE).
