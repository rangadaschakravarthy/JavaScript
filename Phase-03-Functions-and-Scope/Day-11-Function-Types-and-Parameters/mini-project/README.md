# Day 11 Mini-Project — Function Playground

## 1. Overview
The **Function Playground** is an interactive web and Node application demonstrating function declarations, expressions, arrow functions, default parameters, rest parameters, and IIFEs.

## 2. Interactive Controls
- Execute Function Declarations vs Expressions.
- Test single-line Arrow functions with implicit returns.
- Evaluate variadic rest parameters (`...numbers`).
- Trigger IIFEs in an isolated execution box.

## 3. How to Run
- **Browser**: Open `index.html`.
- **Node.js**: Run `node script.js`.
