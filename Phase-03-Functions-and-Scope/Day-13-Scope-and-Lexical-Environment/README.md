# Day 13 — Scope and Lexical Environment

## 📌 Module Overview
Day 13 demystifies how JavaScript tracks variable accessibility and lifecycle across different code boundaries. You will learn Global scope, Function scope, Block scope (`let`/`const` vs `var`), Scope Chain resolution, Lexical Scope, Variable Shadowing, and Execution Environments.

---

## 🎯 Learning Objectives
- Define **Scope** (where variables can be accessed in source code).
- Differentiate **Global Scope**, **Function Scope**, and **Block Scope**.
- Explain why `var` ignores block scope boundaries while `let`/`const` respect block scope.
- Trace the **Scope Chain** from inner scopes to global scope.
- Master **Lexical Scope** (determined by authoring location, not call site).
- Identify **Variable Shadowing** (local declarations hiding outer variables).
- Explain **Lexical Environment** components (Environment Record + Outer Reference).
