# Day 13 Mini-Project — Scope Explorer

## 1. Overview
The **Scope Explorer** is an interactive web-based scope visualizer and simulator. It traces how the JavaScript engine resolves variable references across Global, Function, and Block scope layers.

## 2. Features
- Visualizes Global, Function, and Block scope layers.
- Tests variable lookup for `var` vs `let`/`const`.
- Traces variable shadowing scenarios.

## 3. How to Run
- **Browser**: Open `index.html`.
- **Node.js**: Run `node script.js`.
