# Day 14 Mini-Project — Hoisting Detective

## 1. Overview
The **Hoisting Detective** is an interactive web and Node debugging app that simulates Creation Phase vs Execution Phase hoisting traces, predicting whether code outputs `undefined`, throws `TypeError`, or throws `ReferenceError` (TDZ).

## 2. Features
- Creation Phase vs Execution Phase mental model visualizer.
- Predicts `var` hoisting vs `let`/`const` TDZ behavior.
- Analyzes function declaration vs function expression early calls.

## 3. How to Run
- **Browser**: Open `index.html`.
- **Node.js**: Run `node script.js`.
