# Day 15 Mini-Project — Closure Utility Factory

## 1. Overview
The **Closure Utility Factory** is an interactive web and CLI application featuring closure-based utility generators: Counter Factory, Multiplier Factory, ID Generator, and Encapsulated Bank Account.

## 2. Utilities Included
- `createCounter(start)`: Increment / Decrement / Reset closure methods.
- `createMultiplier(factor)`: Specialized math functions.
- `createIdGenerator(prefix)`: Incremental prefixed string IDs.
- `createEncapsulatedStore()`: Private state storage with public getters/setters.

## 3. How to Run
- **Browser**: Open `index.html`.
- **Node.js**: Run `node script.js`.
