# Day 16 — Callbacks and Higher-Order Functions

## 📌 Module Overview
Day 16 explores JavaScript's functional nature by examining **First-Class Functions**, **Callback Functions**, and **Higher-Order Functions (HOFs)**. You will learn how functions can be assigned to variables, passed into other functions as arguments, and returned as values from other functions.

---

## 🎯 Learning Objectives
- Define **First-Class Functions**: Functions treated like any other value (numbers, strings, objects).
- Define **Callback Function**: A function passed as an argument to another function to be invoked at a designated execution point.
- Differentiate **Synchronous Callbacks** (execute immediately inside caller) vs **Asynchronous Callbacks** (preview `setTimeout` event loop queueing).
- Define **Higher-Order Function (HOF)**: A function that accepts another function as an argument, returns a function, or both.
- Build custom implementations of array HOFs (`myForEach`, `myMap`, `myFilter`).
- Design clean callback interfaces and error-first callback conventions.
