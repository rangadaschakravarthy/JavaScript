# Day 16 Mini-Project — Callback Task Runner

## 1. Overview
The **Callback Task Runner** is an interactive web and CLI task system that accepts queued functions and executes them synchronously through a higher-order runner.

## 2. Features
- Queue tasks as functions.
- Execute tasks with custom completion callbacks.
- Track execution status and task return payloads.

## 3. How to Run
- **Browser**: Open `index.html`.
- **Node.js**: Run `node script.js`.
