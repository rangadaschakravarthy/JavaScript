# Day 17 — Recursion

## 📌 Module Overview
Day 17 introduces **Recursion**: the technique of a function invoking itself to solve smaller sub-instances of a problem. You will learn base cases, recursive cases, call stack mechanics, stack frames, returning values from recursive chains, and recursion vs iteration trade-offs.

---

## 🎯 Learning Objectives
- Define **Recursion**: A function calling itself with modified parameters.
- Identify the mandatory components: **Base Case** (termination guard) + **Recursive Case** (sub-problem call).
- Trace **Call Stack Mechanics**: Stack frame pushes during winding vs stack pops during unwinding.
- Implement classic recursive algorithms: Factorial, Fibonacci, Power, Countdown, String Reversal, Palindrome check, Digit Sum, and Greatest Common Divisor (GCD).
- Compare **Recursion vs Iteration** (memory, stack limits, readability).
- Prevent and debug **Stack Overflow Errors** (`RangeError: Maximum call stack size exceeded`).
