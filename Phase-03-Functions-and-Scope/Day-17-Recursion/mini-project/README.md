# Day 17 Mini-Project — Recursive Number Toolkit

## 1. Overview
The **Recursive Number Toolkit** is an interactive web and CLI application implementing classic recursive algorithms (Factorial, Fibonacci, Power, Sum to N, Digit Sum, String Reversal, and GCD).

## 2. Recursive Functions Included
- `factorial(n)`
- `fibonacci(n)`
- `power(base, exp)`
- `sumDigits(n)`
- `reverseString(str)`
- `gcd(a, b)`

## 3. How to Run
- **Browser**: Open `index.html`.
- **Node.js**: Run `node script.js`.
