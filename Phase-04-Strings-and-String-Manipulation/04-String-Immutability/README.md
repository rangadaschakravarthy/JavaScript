# Day 04 — String Immutability

## 🎯 Day Objective
Deeply understand why JavaScript strings cannot be mutated character-by-character and how variable reassignment creates new string references.

---

## 📌 Prerequisites
- Phase 1 (Variables, Data Types, Operators, Type Coercion)
- Phase 2 (Control Flow, Loops, Conditionals)
- Phase 3 (Functions, Scope, Return Values)

---

## 📚 Topics Covered
- What is immutability
- Why str[0] = "X" fails
- Reassignment vs mutation
- Creating new strings
- const bindings vs value immutability

---

## 💡 Learning Outcomes
- Clear conceptual understanding of What is immutability and Why str[0] = "X" fails.
- Practical ability to write clean, syntactically valid code.
- Confidence to solve real-world problems and technical interview questions.

## ⚠️ Common Mistakes
- Misinterpreting string immutability or assuming indexing mutates string characters directly.
- Mixing up `slice()` and `substring()`.
- Forgetting that string methods return a *new* string and do not mutate original strings.
