## 🎯 Day Objective
Master .length reading/writing, array truncation, sparse arrays vs undefined, and assigning beyond current bounds.

- Truncating arrays (len = 2)
- Expanding arrays
- Sparse arrays (empty slots)
- Assingment beyond bounds

## ⚠️ Common Mistakes
- Confusing array index with element value.
- Expecting non-mutating methods (like `map` or `filter`) to modify the original array in-place.
- Forgetting numeric comparator function `(a, b) => a - b` when calling `.sort()`.
