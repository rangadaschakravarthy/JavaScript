# Day 09 — Array Destructuring

## 🎯 Day Objective
Master array destructuring, rest operator ...rest, default values, skipping elements, variable swapping, and rest vs spread.

- Phase 1 (Variables, Data Types, Operators, Type Coercion)
- Phase 2 (Control Flow, Loops, Conditionals)

- Phase 4 (Strings & Basic Traversal)

## 📚 Topics Covered
- Basic destructuring
- Default values
- Rest operator ...rest
- Skipping elements
- Variable swapping [a, b] = [b, a]

## ⚠️ Common Mistakes
- Confusing array index with element value.
- Expecting non-mutating methods (like `map` or `filter`) to modify the original array in-place.
- Forgetting numeric comparator function `(a, b) => a - b` when calling `.sort()`.
