# Day 03 — Accessing and Modifying Properties

## 🎯 Day Objective
Master dot notation vs bracket notation, reading/updating/adding properties, the delete operator, and dynamic property access obj[key].

---

## 📌 Prerequisites
- Phase 1 (Variables, Data Types, Operators, Type Coercion)
- Phase 2 (Control Flow, Loops, Conditionals)
- Phase 3 (Functions, Scope, Return Values)
- Phase 4 (Strings)
- Phase 5 (Arrays & Array Methods)

---

## 📚 Topics Covered
- Dot notation obj.prop
- Bracket notation obj["prop"]
- Adding & Updating properties
- delete operator & return value
- Dynamic variable key access

---

## 💡 Learning Outcomes

- Practical ability to write clean, syntactically valid code.
- Confidence to solve real-world problems and technical interview questions.

## ⚠️ Common Mistakes
- Confusing dot notation (`obj.key`) with bracket notation (`obj[key]`) when accessing properties dynamically via variables.
- Misunderstanding object mutability or expecting `const` to freeze properties.
- Assuming `obj.key === undefined` proves property non-existence (a property can exist with an `undefined` value).
