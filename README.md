## 📌 Repository Purpose

**JavaScript Mastery** is a structured, exhaustive self-study curriculum built to guide learners from zero prior programming experience to deep technical mastery in modern JavaScript (ES6+), browser APIs, asynchronous execution, language internals, and ecosystem foundations (Node.js & React).

Unlike shallow tutorial repositories, **JavaScript Mastery** prioritizes:
- 🧠 **Depth over brevity**: Every mechanism is explained from first principles.
- 🎯 **Execution accuracy**: Modern standards (TC39 ECMAScript specs) and engine execution models (V8/SpiderMonkey).
- 🛠️ **Hands-on practice**: Hundreds of categorized exercises, output-prediction questions, debugging puzzles, and interactive browser mini-projects.
- 💼 **Interview preparedness**: Real-world interview traps, conceptual questions, and coding challenges for every topic.

## 🎓 Learning Methodology

Every learning day follows a standardized 8-part architectural layout:

1. **`README.md`**: Topic objectives, study schedule, prerequisites, and completion checklist.
2. **`theory/`**: In-depth explanations structured with **What → Why → Syntax → Examples → Step-by-Step Execution → Common Mistakes → Edge Cases → Interview Perspective → Practice → Key Takeaways**.
3. **`examples/`**: Executable JavaScript script files showcasing basic, intermediate, and edge-case code.
4. **`exercises/`**: Categorized coding exercises (🟢 Easy, 🟡 Medium, 🔴 Challenge).
5. **`interview/`**: Interview conceptual questions and tricky output-prediction scripts.
6. **`mini-project/`**: Standalone browser-executable application utilizing only concepts learned up to that day.
7. **`solutions/`**: Exhaustive answers, output breakdowns, and explanations separated from questions.

## 💻 How to Use This Repository

### Prerequisites
- Node.js (v18.0.0 or higher recommended) installed locally.
- A modern web browser (Google Chrome, Mozilla Firefox, or Microsoft Edge).
- Code editor (VS Code recommended).

### Running Code Examples
You can run any `.js` file directly using Node.js in your terminal:
```bash
node Phase-01-JavaScript-Fundamentals/Day-01-Introduction-to-JavaScript/examples/01-hello-world-and-console.js
```

### Running Mini-Projects
Navigate to any day's `mini-project/` directory and open `index.html` in your browser, or serve it using live server tools:
```bash
# Example
cd Phase-01-JavaScript-Fundamentals/Day-01-Introduction-to-JavaScript/mini-project
# Open index.html in browser
```
